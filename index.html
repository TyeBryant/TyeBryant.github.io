Game · Godot · In development

Hull Breach

A portrait, touch-first deduction roguelite for the browser. Each run descends through the decks of a derelict station. Every deck is a hidden grid where revealed tiles show the total threat around them, and a manifest lists exactly what's out there. Clearing safe tiles doesn't win: you hunt down the reactor core and drain threats on purpose.

  • Every board is generated with a solver guarantee, so no deck ever forces a guess.
  • A pure-Python generator and solver is the reference oracle; the GDScript port is checked against it board-for-board in CI.
  • Seeded daily runs and an endless mode, with upgrades bought between runs.
  • Azure Pipelines exports the web build, holds it to a download-size budget and ships it to itch.io with butler.
  • Godot 4
  • GDScript
  • Python
  • Azure Pipelines
  • HTML5

Web app · AWS · In use since 2026

GoobDoob VTT

A custom virtual tabletop for the homebrew D&D 5e campaign I run. It replaced a shared Excalidraw board with something that actually understands the campaign's rules.

  • A shared, real-time battle map: tokens with HP, freehand drawing on separate DM, shared and player layers, and a library of 60-odd spell area templates that snap to the grid.
  • Character sheets import straight from D&D Beyond PDFs, and their roll buttons broadcast to a shared roll feed.
  • A dual-sheet character model for the campaign's timeline-rewind lore, kept in lockstep between TypeScript on the client and C# on the server.
  • The whole campaign lives here too: a zoomable world map with private pins, party and loot tracking, and lore with per-player visibility.
  • Every session opens with a “Previously on…” recap, backed by an archive of read-aloud recaps, player notes and search.
  • Serverless on AWS, sized to run for under AU$2 a month.

Infrastructure · AWS · Azure DevOps

Home game-server relay

Hosting a dedicated game server from a home PC, without port forwarding, a static IP, or paying for a game-sized cloud machine. A tiny ARM instance on AWS takes the public traffic; the home machine dials out to it, and the tunnel carries players back home.

  • The home PC opens the rathole tunnel outbound, so the router needs no open ports.
  • The relay is one CloudFormation stack: instance, Elastic IP, security group and DNS record.
  • Azure Pipelines deploys the stack and, through a self-hosted agent on the home box, installs and updates the game server itself.
  • An idempotent PowerShell bootstrap means a replacement machine is one script away.

About

I come from a games programming background: a Bachelor of Games Development at SAE, then an internship at 89Friends that turned into nearly five years of contract work, including leading an augmented-reality tabletop product. That work is what pulled me towards databases, payments and backend services.

Outside work it's still games, plus the homebrew D&D campaign I run, which is how a virtual tabletop ended up on this page. I like software that's cheap to run, easy to redeploy and pleasant for the people using it.
